# 工程化不只是目录好看

一个项目是否可靠，关键在于能否重复安装、开发、构建和部署。

## MVP 的工程基线

1. 依赖和脚本在 `package.json` 中保持一致。
2. 内容结构由 schema 校验。
3. 页面链接统一考虑部署 base path。
4. GitHub Actions 使用固定 Node.js 主版本并缓存 npm。
5. 本地先执行 `npm run check` 与 `npm run build`。

## 迭代建议

先确保最小功能闭环，再逐步加入全文搜索、阅读进度、目录导航、评论系统和数据分析。不要在第一个版本就引入不必要的后端服务。
