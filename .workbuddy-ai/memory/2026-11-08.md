# 2026-11-08 工作日志

## 博客源码问题修复

对 GitHub Pages 博客项目 (JonathanJoe-tech-blog) 进行了全面源码审查，发现并修复了 6 个问题：

### 修复内容

1. **astro.config.mjs 硬编码 base/site**
   - 原代码硬编码 `site: 'https://zhangjintao314.github.io/JonathanJoe-tech-blog/'`（site 不应包含仓库名路径）
   - 原代码硬编码 `base: '/JonathanJoe-tech-blog/'`，README 声称自动识别但实际没有
   - 修复：新增 `resolveBase()` 和 `resolveSite()` 函数，从 `GITHUB_REPOSITORY` 环境变量自动推断，支持 `SITE_BASE` 手动覆盖

2. **Header.astro 导航链接拼接脆弱**
   - 原代码使用 `import.meta.env.BASE_URL.replace(/\/$/, "")` 拼接，逻辑复杂
   - 修复：提取 `normalizedBase` 和 `url()` 辅助函数，统一处理路径拼接和当前页高亮

3. **[slug].astro 中多余的扩展名 replace**
   - 原代码 `post.id.replace(/\.(md|mdx)$/i, "")`，但 Astro 5 中 `post.id` 已不含扩展名
   - 修复：直接使用 `post.id`，与 `covers/[slug].svg.ts` 保持一致

4. **rss.xml.ts 中 link 缺少 base path**
   - 原代码 `link: \`blog/${post.id}/\``，在项目仓库模式下生成错误 URL
   - 修复：改为 `link: \`${base}blog/${post.id}/\``

5. **deploy.yml 中多余的 GITHUB_ACTIONS 环境变量**
   - GitHub Actions 环境本身已自动设置该变量
   - 修复：移除冗余配置

6. **README.md 与代码不一致**
   - 目录结构缺少 Header.astro、Footer.astro、github.ts
   - README 说"没有接入搜索索引服务"，实际已集成 Pagefind
   - README 说"将 YOUR_GITHUB_USERNAME 替换为..."，实际已填好用户名
   - 修复：同步更新所有不一致的描述
